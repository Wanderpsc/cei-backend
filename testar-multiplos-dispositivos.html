🧪 Testes - Múltiplos Dispositivos Simultâneos

CEI v3.6.0 - Controle Escolar Inteligente

🔐 Teste 1: Login Duplicado em Navegadores Diferentes

  • Abra dois navegadores diferentes (Chrome e Firefox, ou Chrome e Edge)
  • No Navegador 1, acesse: http://localhost:3000
  • Faça login com: demo / demo2026
  • Você deve estar logado e ver a dashboard
  • No Navegador 2, acesse também: http://localhost:3000
  • Faça login com as MESMAS credenciais: demo / demo2026
✅ Esperado: Ambos os navegadores devem estar logados simultaneamente
⚠️ Antes (v3.5.x): O segundo navegador teria erro "Licença já ativa"
✅ Agora (v3.6.0): Ambos funcionam perfeito!

📱 Teste 2: Login em Modo Privado/Incógnito

  • Abra uma aba normal e acesse: http://localhost:3000
  • Faça login com: demo / demo2026
  • Abra uma aba em modo incógnito/privado (Ctrl+Shift+N ou Cmd+Shift+N)
  • Na aba incógnito, acesse: http://localhost:3000
  • Faça login com as MESMAS credenciais
✅ Esperado: Modo incógnito também deve funcionar com a mesma conta
💡 Dica: Modo incógnito não compartilha localStorage, então pensa em cada aba como um "dispositivo" diferente

🔄 Teste 3: Logout Independente

  • Tenha 2 navegadores abertos (ambos logados com demo)
  • No Navegador 1, clique em Logout
  • Você será deslogado no Navegador 1
  • No Navegador 2, recarregue a página (F5)
✅ Esperado: Navegador 2 deve continuar logado mesmo após logout no Navegador 1
⚠️ Antes (v3.5.x): Logout em um dispositivo deslogava todos
✅ Agora (v3.6.0): Cada sessão é independente

💾 Teste 4: Verificar localStorage

  • Abra o navegador e faça login: demo / demo2026
  • Abra o Developer Tools (F12)
  • Vá para a aba Application → Local Storage
  • Procure pelas chaves que começam com cei_
📍 Chaves importantes a procurar:
cei_usuario_logado: Dados do usuário ativo
cei_instituicao_ativa: ID da instituição
cei_license: Informações da licença ativada

✅ Resumo dos Testes

Quando todos os 4 testes passarem:

  • Login múltiplo está funcionando
  • Cada dispositivo tem sua sessão independente
  • Dados estão sendo armazenados corretamente
  • System está pronto para produção

📚 Stack Tecnológico

Frontend: React 18 + Material-UI

Backend: Node.js + Express

Armazenamento: localStorage (frontend) + Supabase (backend)

Session Management: Map de Maps (múltiplos dispositivos)

Configurar Supabase (sem código)

Use esta tela para configurar a nuvem sem editar arquivos. A configuracao fica salva apenas neste navegador/dispositivo.

Para todos os dispositivos: preencha o arquivo public/supabase-runtime-config.js no deploy ou configure .env.local antes do build. O localStorage desta tela nao sincroniza a configuracao entre aparelhos.

Depois de salvar, abra o sistema e recarregue a pagina. Se outros dispositivos ainda ficarem sem dados, faltou configurar a nuvem de forma compartilhada no deploy.
